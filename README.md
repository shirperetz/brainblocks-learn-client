# BrainBlocks — עולם החשבון (learn-client)

משחק למידת חשבון בעברית לילדים, כיתות א׳–ו׳. React 19 + Vite.

- **בחירת כיתה בהתחלה** — כל ילד מקבל את הרמה שלו.
- **אי המספרים (כיתות א׳–ב׳)** — משחקים מדוברים, כמעט בלי קריאה: 🐲 הדרקון הרעב (ספירה עד 20), 🎈 בלונים (חיבור וחיסור עם תמונות). 6 שלבים לכל משחק, כוכבים נשמרים.
- **נושאים (כיתות ג׳–ו׳)** — חיבור, חיסור, כפל, חילוק, השוואה, סדרות, בעיות מילוליות; המספרים גדלים לפי הכיתה.
- **🤔 לא הבנתי** — הסבר צעד-אחר-צעד לשאלה: שני ההסברים הראשונים נבנים בקוד (תמיד נכונים, אף פעם לא התשובה עצמה), ומהלחיצה השלישית בינה מלאכותית **מקומית** (Ollama במחשב, שום דבר לא יוצא ממנו) מנסחת דרך נוספת — רק אם עברה סינון בשרת (עברית, רק המספרים הנכונים, בלי חישובים שגויים, בלי התשובה). הילד לא מקליד כלום. בכיתות א׳–ב׳ ההסבר גם מוקרא בקול.
- **🔥 אתגר יומי** — 5 שאלות ביום, עם רצף ימים.
- **⏱️ 60 שניות** — כמה תספיקו בדקה, מול השיא של עצמכם.
- **🔁 חזרה על מה שהיה קשה** — טעויות קודמות חוזרות עד שעונים נכון.

## הרצה
צריך את השרת ([brainblocks-server](https://github.com/shirperetz/brainblocks-server), Spring Boot על 8080 + MySQL).

```bash
npm install
npm run dev -- --port 5174
npm test        # בדיקות למחולל הסיבובים
```

ה-AI (אופציונלי): [Ollama](https://ollama.com) עם `aya-expanse:8b` (אפשר לשנות ב-`brainblocks.ai.model` בשרת).

הקבצים ב-`public/audio` נוצרו מראש בקול סינתטי (`scripts/make_audio.py`).
